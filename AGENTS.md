# Inject Z project instructions

- For every application change or update, review the user guide and update it to explain any changed or added user-facing behavior, controls, installation, limitations, and workflows. Preserve existing instructions that still apply.
- Keep the in-app guide in `Assets/InjectZ_User_Guide.html` current; also update `Docs/USER_GUIDE.md` and the root `USER_GUIDE.md` when their coverage is affected. The bundled HTML is the guide opened by the Help menu.
- Verify guide content against the actual implementation and include the updated bundled guide in the updater manifest when it changes.
