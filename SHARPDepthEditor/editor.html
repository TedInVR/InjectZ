New change — select an area, name it, and save.

For the lettering, choose Exclude rectangle and drag one box around the entire text block. For the propeller, use a broad Exclude brush. Hold Space and drag to pan in any direction. At higher zoom, scroll within the image to reach small details. The circle shows the brush footprint, including the current zoom. Radius 5 means a brush approximately 10 selection-image pixels across. Direct painting works on the visible mask even if automatic sample changes have not been recalculated. Undo/Redo here cover brush strokes and direct rectangles; use Command-Z / Command-Shift-Z. Automatic samples and saved-edit deletion are separate actions.

Saved changes marked Apply in next render affect the output. Unchecking one keeps it saved but skips it.

Keyboard zoom: point at the area you want, hold Z, and tap + (or =) / −. Hold the combination to zoom continuously. Release either key to stop. Hold Z + 0 to return to Fit. Range: Fit to 32×. Moving over the image activates these shortcuts; no background click is needed. [ / ] shrinks/enlarges the brush (hold to repeat). Point at an automatic red/green sample dot and press Delete to remove it after confirmation.

Negative values trim every selected patch; positive values expand them. Try −4 or −5 for a gap around foreground edges. Each value is measured from the current un-resized selection, so changing −4 to −5 shrinks it by one more pixel. The preview updates when you release the slider. Save Changes before rendering.

Automatic selection — use initially; direct corrections stay locked

Draw an Automatic selection box around the region, then add automatic include/exclude samples if needed. Find Selection recalculates the automatic portion globally, but reapplies every direct edit afterward. Later direct edits override earlier direct edits wherever they overlap.

3. Save your depth change

For a gradient, drag from zero adjustment to full adjustment. For rounded shaping, drag from the strongest center to its zero-strength radius. Feather softens inward at the selection boundary. These preserve SHARP’s existing contours; they do not create new hidden geometry. Sky repair uses Uniform shift.

Saved-edit deletion controls

Give the selection a name and choose its type, then click Save As New Change. Your saved change appears on the right; further brush strokes keep revising that same change. Click New Separate Change to select a different area while keeping saved changes. Positive adjustment = closer; negative = farther. Loading an edit lets you replace its saved selection.

4. Render your saved changes

Repair mode requires one enabled negative Sky/background edit. You can also enable separate Object depth adjustments. It reconstructs one background shared by both eyes and treats the background as one distant plane. Regular conversions wait until the editor session is closed. Save Changes before quitting Inject Z.
