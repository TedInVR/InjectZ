# External components (not bundled)

- Apple SHARP (`apple-aiml-research/ml-sharp`): single-image 3D Gaussian representation. Separate source/checkpoint licenses apply.
- Apple Depth Pro (`apple-aiml-research/ml-depth-pro`): SHARP's paper describes a Depth Pro backbone, adapted during SHARP training.
- nunif / IW3 (`nagadomi/nunif`): depth-guided stereo conversion used as a separate runtime.
- Pillow, NumPy, and Apple Photos/AppKit/ApplicationServices: integration dependencies.
- Dubois anaglyph matrices: see attribution link in SharedStereoFormats.py.

This exchange snapshot includes integration source, not third-party model weights or third-party repositories. Confirm rights and licenses before broader publication.
