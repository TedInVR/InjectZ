# Voluntary support

Open Help → Support Inject Z… and choose Ko-fi, PayPal, or Patreon. Each opens the system default browser only when clicked. Close with Close, Escape, the red close button, or Command-W.

Public destinations:
- https://ko-fi.com/tedwhitten
- https://paypal.me/theodorewhitten1
- https://patreon.com/TedWhitten

These support Ted in VR’s creative work, including Inject Z and other projects. Contributions never unlock app features and no donation reminders appear. Patreon is for recurring membership; use Ko-fi or PayPal for a one-time contribution. Payment processing takes place on those services, not inside Inject Z. The developer may see a creator dashboard when signed in; use a private browser window to inspect the public page. Successful navigation is not proof of a tested payment or payout.
